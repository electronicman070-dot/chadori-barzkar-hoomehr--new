چادری برزکار — نسخه‌ی نمایشی قابل انتشار

فایل اصلی: index.html

آزمایش محلی:
1) فایل index.html را در Chrome باز کنید.
2) برای دیدن پنل مدیریت روی «پنل مدیریت» بزنید.
3) رمز نمایشی پنل: 1234
4) تغییرات و محصولات اضافه‌شده فقط در همان مرورگر ذخیره می‌شوند.

انتشار رایگان با GitHub Pages:
1) در GitHub یک مخزن جدید بسازید (مثلاً chadori-barzkar).
2) فایل index.html را در ریشه‌ی مخزن آپلود کنید.
3) در مخزن به Settings > Pages بروید.
4) در بخش Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کنید.
5) Branch را روی main و پوشه را روی /(root) بگذارید و Save کنید.
6) پس از آماده‌شدن انتشار، GitHub نشانی سایت را در همان صفحه نشان می‌دهد.

مهم — قبل از استفاده‌ی واقعی:
- این یک نمونه‌ی فرانت‌اند است، نه فروشگاه عملیاتی کامل.
- ورود پنل مدیریت با رمز 1234 فقط نمایشی است و برای سایت عمومی امن نیست. پیش از انتشار عمومی، پنل باید با احراز هویت واقعی و کنترل دسترسی سمت سرور پیاده‌سازی شود؛ رمز نمایشی را برای استفاده‌ی واقعی به کار نبرید.
- تغییرات محصولات، عکس‌ها و نشانی به‌صورت محلی در مرورگر ذخیره می‌شوند، نه برای همه‌ی مشتریان در اینترنت.
- پرداخت واقعی، ثبت سفارش، مدیریت مشتریان و ارسال پیام هنوز متصل نیستند.
- بخش پرو مجازی در این نسخه فقط عکس انتخابی را نشان می‌دهد؛ برای قرار دادن واقعی چادر روی عکس، سرویس هوش مصنوعی جداگانه لازم است.
- نقشه فعلاً نمایشی است؛ برای نمایش مکان دقیق، نشانی یا مختصات واقعی و یک سرویس نقشه اضافه کنید.
- عکس مشتری را به سرویس خارجی نفرستید مگر پس از انتخاب سرویس معتبر، بررسی سیاست حریم خصوصی و گرفتن رضایت روشن کاربر.
- فونت از Google Fonts بارگذاری می‌شود؛ برای کارکرد بهتر بدون اینترنت می‌توان فونت را محلی قرار داد.
